# Week 1 Assignment: Python Fundamentals for Data Analytics

A beginner-friendly Python assignment covering the fundamental concepts required for Data Analytics, including input/output, variables, data types, operators, conditional statements, loops, functions, strings, collections, file handling, and a mini project.

## 📌 Overview

This repository contains the complete Python source code for **Week 1: Python Fundamentals for Data Analytics**.

The assignment focuses on building a strong foundation in Python programming and applying the concepts through practical programs and a **Student Record Management System**.

## 🎯 Objectives

By completing this assignment, the following Python fundamentals are practised:

- Input and output
- Variables and basic data types
- Arithmetic operators
- Conditional statements
- `for` and `while` loops
- User-defined functions
- Strings and string methods
- Lists, tuples, dictionaries, and sets
- Basic file handling
- Building a menu-driven Python application

## 📝 Tasks Covered

### Task 1 — Python Basics
- Prints a welcome message.
- Takes the student's name, college name, and branch as input.
- Displays the entered information in a formatted output.

**File:** `task1_python_basics.py`

### Task 2 — Variables & Data Types
Demonstrates:
- Integer
- Float
- String
- Boolean
- Checking data types using `type()`

**File:** `task2_variables_and_data_types.py`

### Task 3 — Operators
Creates a simple calculator that performs:
- Addition
- Subtraction
- Multiplication
- Division
- Modulus

The program also handles division by zero safely.

**File:** `task3_operators.py`

### Task 4 — Conditional Statements
Takes marks as input and assigns a grade using `if`, `elif`, and `else`.

Grade ranges used:
- `90+` → A
- `75–89` → B
- `60–74` → C
- Below `60` → Fail

The program also checks for marks outside the `0–100` range.

**File:** `task4_conditional_statements.py`

### Task 5 — Loops
Demonstrates:
- Printing numbers from 1 to 20 using a `for` loop
- Printing the multiplication table of a user-entered number
- Printing even numbers from 1 to 50 using a `while` loop

**File:** `task5_loops.py`

### Task 6 — Functions
Defines and uses two user-defined functions:
- A function to calculate the square of a number
- A function to calculate the average of three numbers

Both functions are called using user input.

**File:** `task6_functions.py`

### Task 7 — Strings & Collections
Demonstrates:

**String operations**
- `upper()`
- `lower()`
- `replace()`
- `find()`

**List operations**
- `append()`
- `remove()`
- `sort()`

**Tuple**
- Tuple creation
- Indexing

**Dictionary**
- Storing student information

**Set**
- `add()`
- `remove()`

**File:** `task7_strings_and_collections.py`

### Task 8 — Basic File Handling
The program:
- Creates a text file
- Writes an introduction to the file
- Reads the file contents
- Displays the contents

**File:** `task8_basic_file_handling.py`

### Task 9 — Student Record Management System
A menu-driven mini project that allows the user to:

1. Add student details
2. Display all student records
3. Search for a student by name
4. Delete a student record
5. Exit the program

Student records are stored using a **list of dictionaries**.

**File:** `task9_mini_python_project.py`

## ▶️ How to Run

Make sure Python 3 is installed on your system.

Run any task from the terminal using:

```bash
python filename.py
```

For example:

```bash
python task1_python_basics.py
```

For Task 8, the program creates `introduction.txt` in the working directory when it is executed.

For Task 9, use the menu displayed in the terminal to add, view, search, and delete student records.
